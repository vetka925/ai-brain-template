# Reflections

Concrete assistant errors and their corrections, so a later session can find the lesson when a similar task comes up. New entries go below this section; resolved entries move unchanged to [reflections-archive](reflections-archive.md) at a review. Permanent rules live in [conventions](conventions.md); proposals in [rule-proposals](rule-proposals.md).

## Record an error now

A direct correction from the owner permits one short entry without another question; also record a self-found error when it violated a source, privacy, safety or scope rule. Do not record every harmless variation. State:

1. date and the exact author model (`**Author model.** <exact session model>`; a product label is not enough; one model per entry);
2. what happened, with a link to the evidence;
3. why, and what concrete change or check was made; «not verified» if none yet.

Before a task that resembles a past failure, search this page for the subject and follow the linked correction. Own the action plainly; do not simulate guilt.

## Review

On the owner's request (or when the session hook says the review is overdue), read the entries with their evidence, note which corrections held and which repeated, move resolved entries to the archive unchanged, and set `reviewed:` above. A repeated error means the existing safeguard was insufficient; propose a change in rule-proposals rather than adding another prohibition.
